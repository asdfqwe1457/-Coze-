# 沉浸式历史故事Coze扣子工作流智能体批量自动生成爆款视频教程

这套就是市面上售卖的【权谋沉浸式历史第一人称】扣子工作流，主打动漫古风暗黑色调，适合抖音历史权谋号，自动批量产出，输出剪映草稿，可二次修改。

## ✨ 这套模板核心卖点（你写推广文案直接用）

1. 输入历史人物 / 权谋主题，全自动生成完整短视频
2. 统一动漫国风权谋画风（就是图里这种暗黑古风漫画质感，武将、朝堂、权谋氛围感）
3. 批量数组循环，一次丢多个历史人物，排队自动生成，不用手动一条一条跑
4. 输出**剪映草稿链接**，打开直接改字幕、调 BGM、微调画面，零基础可用
5. 1 分钟左右出一条成片，自带钩子文案、分镜、封面提示词、旁白配音、SRT 字幕
6. 工作流支持一键导入 Coze，配套全套提示词、JS 字幕代码、节点配置

## 🧱 工作流节点顺序（和这套权谋模板原版一致）

> 
> 主题：权谋向沉浸式历史，第一人称独白，主打遗憾、阴谋、朝堂博弈、乱世悲情

1. **开始节点**：变量
   - `topic_list`：数组，批量主题，示例：["韩信","霍光","张居正","荀彧","庞涓"]
   - `style`：固定为【暗黑国风动漫，厚涂漫画，权谋古风，暗调，电影光影，线条硬朗，血色氛围感，9:16 竖屏】（对应封面画风）
   - `voice`：低沉说书男声，语速 0.85，沧桑厚重，适配权谋故事
   - `video_len`：60s（主流爆款时长）
2. **大模型节点 1：生成权谋剧本 + 分镜（核心提示词）**

```
你是抖音历史权谋爆款编剧，采用历史人物第一人称沉浸式独白，暗黑遗憾风格，适配国风动漫短视频。
主题：{{item}}
总时长：{{video_len}}秒
风格：权谋悲剧，朝堂博弈，乱世无奈，强情绪钩子，开头3秒抓住眼球，结尾留评论引导，不要枯燥史料。
输出严格JSON，禁止多余文字：
{
"title":"视频标题",
"cover_text":"封面大字（2-4个字，如权谋、孤臣、悲歌）",
"cover_prompt":"封面图提示词，暗黑国风动漫，{{style}}",
"tags":["#历史","#权谋","#古代人物","#沉浸式历史","#历史悲歌"],
"shot_list":[
{"narration":"旁白台词","shot_prompt":"画面提示词，保持暗黑动漫国风","duration":"单段时长"}
]
}
```

3. **循环节点：遍历 shot_list**
逐个生成分镜图片，提示词强制锁画风：暗黑国风漫画，硬朗线条，暗调，古风朝堂 / 古战场，无畸形五官，电影级氛围感
4. **Seedance 视频生成节点**
模式：首帧 + 尾帧图生成动态片段，缓慢推镜、轻微运镜，不要大幅度抖动；模型：doubao-seedance-pro，9:16 竖屏
5. **TTS 语音节点**：旁白配音，固定沧桑男声，语速放慢，适合权谋叙事
6. **JS 代码节点：自动生成 SRT 字幕（直接复制）**

```
// 输入shot_list数组，输出srt字幕
let srt = "";
let currentTime = 0;
const formatTime = (sec)=>{
    let h = Math.floor(sec/3600).toString().padStart(2,'0');
    let m = Math.floor((sec%3600)/60).toString().padStart(2,'0');
    let s = Math.floor(sec%60).toString().padStart(2,'0');
    let ms = ((sec%1)*1000).toFixed(0).padStart(3,'0');
    return `${h}:${m}:${s},${ms}`
}
for(let i=0;i<shot_list.length;i++){
    let item = shot_list[i];
    let start = currentTime;
    let end = currentTime + Number(item.duration);
    srt += `${i+1}\n${formatTime(start)} --> ${formatTime(end)}\n${item.narration}\n\n`
    currentTime = end;
}
return {srt_subtitle:srt}
```

7. **剪映插件【创建剪映草稿】**
自动拼接视频片段 + 音频轨道 + 字幕轨道；BGM 搭配低沉古风权谋纯音乐，音量压低；自动添加渐入渐出转场；把封面图设置为视频封面，返回草稿链接
8. **汇总输出节点**：一次性返回全部标题、封面提示词、剪映链接、话题标签清单

## 📝 批量实操步骤

1. 打开 Coze 扣子，新建【低代码工作流】，依次搭建上面节点，先单条测试一个人物（比如韩信），检查画风、文案、配音是否是权谋悲情风格
2. 测试没问题，填入批量数组：`["伍子胥","李牧","刘伯温","晁错","周瑜"]`
3. 启动试运行，循环自动排队生成；不建议单次超过 6 条，积分消耗很大，容易超时失败
4. 拿到剪映草稿链接，复制打开剪映，按需调整字幕大小、BGM 音量，直接导出发布
